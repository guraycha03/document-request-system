
Document Request System — Final System Overview
1. System Overview

The Document Request System is a web-based internal request management system designed for an organization where employees need to request different types of company documents and internal services.

Instead of submitting requests through paper forms, chat messages, emails, or verbal communication, employees can submit their requests through one centralized system. Authorized staff can then review the requests, process them, update their status, and maintain an organized record of all submitted requests.

The system supports different categories of requests, allowing it to handle more than simple document requests while still keeping the main purpose focused on managing organizational requests.

2. Main Users

The system has three main users:

1. Requester

The requester is an employee who needs a company document or internal service.

They can:

Submit a request
Select a request category
Specify the requested item/service
Enter the quantity
Provide the purpose of the request
View the status of their requests
2. Staff Reviewer

The staff reviewer is an authorized employee responsible for checking submitted requests.

They can:

View incoming requests
Review request details
Check the requester's information
Process requests
Update request status
View previous requests
3. Record Keeper

The record keeper maintains the organization's request records.

They can:

View stored request records
Search and review request history
Monitor request statuses
Maintain organized request information
Use records for reference and reporting
3. Request Categories

The system can support four major categories.

A. HR & Document Requests

Requests related to employee records and official company documents.

Examples:

Certificate of Employment
Employment Verification
Certificate of Compensation
Copy of Employment Contract
Employee Information Update

Example:

An employee requests a Certificate of Employment for a bank loan application.

B. IT & Technical Support

Requests related to company technology and employee technical needs.

Examples:

Computer repair
Software installation
Account access
Password assistance
Network/Wi-Fi issue
Equipment troubleshooting

Example:

An employee submits a request because their workstation cannot connect to the company network.

C. Facilities & Workplace

Requests involving the employee's workplace or company facilities.

Examples:

Office equipment repair
Workspace issue
Access card replacement
Furniture repair
Room/facility request
Office supply request

Example:

An employee reports a damaged office chair and submits a maintenance request.

D. Administrative Services

General internal services that do not belong to HR, IT, or facilities.

Examples:

Meeting room request
Company vehicle request
Printing request
Official communication request
Event support request
Administrative certification

Example:

An employee requests a meeting room for an internal department meeting.

7. Important Scope for Laboratory 2

For the current laboratory, we should not implement all of these features yet.

The laboratory specifically requires us to build the requests data model with:

id
requester_name
requester_email
item_name
quantity
purpose
status
created_at
updated_at

So for Lab 2, we can demonstrate the concept using different request types, but the actual migration should follow the instructor's required structure exactly.

For example:

HR & Documents	Certificate of Employment	1	Bank loan	Pending

This satisfies the laboratory's requirement for three realistic fictional sample requests.
